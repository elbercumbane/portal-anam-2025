📋 PRIMEIRA VEZ - SETUP COMPLETO AUTOMÁTICO
═══════════════════════════════════════════════════════════════

Execute um destes arquivos (duplo clique):

   ✅ SETUP-AUTOMATICO.bat          (Windows - mais fácil)
   ✅ setup-completo-auto.ps1       (PowerShell)

Este script faz TUDO automaticamente:
   ✓ Instala Vercel CLI se necessário
   ✓ Faz login no Vercel
   ✓ Instala dependências
   ✓ Faz deploy do backend
   ✓ Faz deploy do frontend
   ✓ Mostra próximos passos
